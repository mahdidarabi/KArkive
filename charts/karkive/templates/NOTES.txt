KArkive operator {{ .Chart.AppVersion }} installed in {{ .Release.Namespace }}.

Install a Backup or Restore CR (`engine`: postgres, mariadb, or redis):

  kubectl apply -f config/samples/karkive_v1alpha1_backup.yaml
  kubectl apply -f config/samples/karkive_v1alpha1_restore.yaml

The operator creates a ConfigMap, optional PVC, and CronJob named `karkive-backup-<cr-name>` or `karkive-restore-<cr-name>`.
Backup and Restore status include the last finished Job outcome (`status.lastJob`).

Metrics are served on port {{ .Values.metrics.port }} via Service {{ include "karkive.fullname" . }}-metrics.
Enable scrape, alerts, and the Grafana dashboard with:

  --set metrics.serviceMonitor.enabled=true
  --set metrics.prometheusRule.enabled=true
  --set metrics.grafanaDashboard.enabled=true
